---
title: "Telemetry Filter"
---

Provides telemetry values that represent the mean of the last N values of a telemetry stream.

<ul>
  <li><strong>Type key:</strong> `telemetry-mean`</li>
  <li><strong>Creatable:</strong> Yes</li>
  <li><strong>Composition:</strong> No</li>
  <li><strong>Source:</strong> [`src/plugins/telemetryMean/plugin.js`](https://github.com/nasa/openmct/blob/master/src/plugins/telemetryMean/plugin.js)</li>
</ul>

## Properties Beyond the [Envelope](../object-envelope/index.md)

| Property | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `telemetryPoint` | string | Yes | — | The source telemetry object's key string (namespace:key). Despite the create-form's textfield control, this is expected to resolve to an existing telemetry object. |
| `samples` | number | Yes | `10` (`DEFAULT_SAMPLES`) | Number of most-recent samples averaged into the rolling mean. |
| `telemetry` | object | No | Generated by `initialize()` | Telemetry metadata for this object's own output: one domain value per registered time system, plus a single range-hinted value. Generated automatically at creation time from `openmct.time.getAllTimeSystems()` — not something you typically hand-author, but it must be present for the object to function as a telemetry source. See the example below for the shape it takes. |

No `configuration` wrapper — all of the above are top-level properties.

## Example

```json
{
  "name": "Subsystem Signal Mean",
  "type": "telemetry-mean",
  "location": "671327d3-e625-435d-8030-1049fc29b9dd",
  "identifier": { "key": "3e4f5a6b-mean-uuid", "namespace": "" },
  "telemetryPoint": "taxonomy:~Spacecraft~SubSystem~parameterName",
  "samples": 20,
  "telemetry": {
    "values": [
      { "key": "utc", "name": "Time", "hints": { "domain": 1 } },
      { "key": "value", "name": "Value", "hints": { "range": 1 } }
    ]
  }
}
```
